# Testing Quick Reference Card

## 🚀 Daily Development (WSL Users)

```bash
# 1. Fast local tests (seconds)
pnpm run test:local

# 2. Check types and lint
pnpm run typecheck
pnpm run lint

# 3. Build to verify compilation
pnpm run build
```

---

## ✅ Pre-Commit Validation

```bash
# Quick CI check via Docker (~2 minutes)
pnpm run ci:quick
```

**What it runs:**
- ✓ Lint
- ✓ Typecheck
- ✓ Build (all packages)
- ✓ Unit tests (17 tests)
- ✓ Integration tests (12 tests)

---

## 🎯 Pre-PR/Push Validation

```bash
# Full CI check via Docker (~9 minutes)
pnpm run ci:full
```

**What it runs:**
- ✓ Everything in `ci:quick` PLUS:
- ✓ Angular component tests (Karma)
- ✓ E2E tests (Playwright)

---

## 📦 First-Time Setup

```bash
# 1. Install act CLI
brew install act  # macOS
# OR
curl https://raw.githubusercontent.com/nektos/act/master/install.sh | sudo bash  # Linux

# 2. Pull Docker image (once)
docker pull ghcr.io/catthehacker/ubuntu:act-24.04

# 3. Verify setup
pnpm run ci:quick
```

---

## ⚠️ Important Notes

- **DO NOT** run `pnpm run test` directly on WSL (will hang)
- **DO NOT** run `pnpm run test:component` directly on WSL (will hang)
- **DO** use `pnpm run test:local` for fast feedback
- **DO** use `pnpm run ci:quick` or `ci:full` for complete validation

---

## 🔧 Troubleshooting

### "Docker image not found"
```bash
docker pull ghcr.io/catthehacker/ubuntu:act-24.04
```

### "act: command not found"
```bash
brew install act  # macOS
```

### Tests hanging
**Use Docker commands** (`ci:quick` or `ci:full`) instead of direct test commands on WSL.
